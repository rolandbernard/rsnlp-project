\begin{abstract}
This project performs an evaluation of Large Language Models (LLMs) by designing and implementing a new \inlinecode{clemgame} based on the Deal or No Deal (DoND) negotiation scenario. The core capabilities being assessed in this project are the performance of LLMs in interactive negotiation, requiring strategic communication and decision-making under uncertainty. The evaluation involves a dynamic, dialogue-based environment where two LLM agents negotiate the division of a set of items, with each agent being given a private value function unknown to the other player. A range of recent closed- and open-weight models were evaluated across cooperative and semi-competitive game modes in multiple languages. Performance was measured using metrics for rule-following, agreement rates, and the quality of outcomes with respect to Pareto efficiency. Key findings indicate that while newer, larger models like GPT-4.1 and Mistral Large demonstrate superior rule adherence and negotiation outcomes, most models struggle with consistent strategic reasoning. These results highlight critical areas for improvement in LLM development and underscore the value of interactive benchmarks for a more holistic evaluation of model capabilities.
\end{abstract}
