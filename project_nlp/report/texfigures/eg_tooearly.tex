  \caption{Example game episode generated through self-play using the o4-mini model. The game was played using the semi-competitive game mode. It can be seen that player A has made a proposal before even discussing the possible division of items. The only information exchanged in these dialogues are the preferences of player B. Surprisingly, the players were still able to reach an agreement. This could be either due to luck, or because, since we are using self-play, the models could potentially predict what the other player was going to do. In any case, this strategy could obviously never work when interacting with a human player.}
