  \caption{Example game episode generated through self-play using the GPT 4 model. The game was played using the cooperative settings. We can observe that even though the GPT 4 model was one of the best performing, especially for this game mode and language combination, this example still shows many deficiencies indicating a lack of strategy and grounding. First, already in the first message, player B misrepresents their value function, saying that they are particularly interested in the pliers, when they don't value them at all. It should be noted that in the cooperative setting it does not make any sense to lie to the other player. Furthermore, we can see in the dialogue that the players try to "balance things out", something that also does not make any sense in cooperative play.}
