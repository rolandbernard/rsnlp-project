Seminar Presentation
====================

This directory contains a seminar presentation about the paper “Contrastive Learning for Sequential Recommendation”, available [here](https://arxiv.org/pdf/2010.14395). The presentation slides can be found at `main.pdf`, and have been generated from the LaTeX file at `main.tex`.

> Xu Xie et al. (2022). “Contrastive learning for sequential recommendation”. In: 2022 IEEE 38th international conference on data engineering (ICDE). IEEE, pp. 1259–1273
